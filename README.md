## Hola, soy Hank 👋

Desarrollador de software enfocado en aplicaciones web con **Python** y **Vue.js**. Me gusta construir sistemas completos: desde la API y la base de datos hasta la interfaz que usa la gente.

### 🚀 Proyecto destacado: Invexa

Sistema de inventario y punto de venta para una ferretería en Perú, con control de stock por kardex, ventas con pagos mixtos, deudas, reportes y configuración de la tienda.

- 🔧 **Backend:** [invexa-backend](https://github.com/HANKZ08/invexa-backend), con Django REST Framework, PostgreSQL y pruebas con 97 % de cobertura.
- 🎨 **Frontend:** [invexa-frontend](https://github.com/HANKZ08/invexa-frontend), con Vue 3, TypeScript y Vite.
