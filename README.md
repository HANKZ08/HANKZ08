### 👨‍💻 Sobre mí

Soy **Software Engineer** y **Web Developer**. Construyo aplicaciones web de principio a fin: APIs robustas en Python y interfaces claras en Vue con TypeScript. Me importa que el software sea correcto por dentro (pruebas, validación, documentación de la API) y sencillo de usar por fuera.

- 🔭 Armando un portafolio de proyectos web completos, cada uno con backend y frontend.
- 🌱 Aprendiendo a diseñar sistemas más grandes: arquitectura, CI/CD y calidad de código.
- 🤝 Abierto a colaborar en proyectos de Python, Django, FastAPI o Vue.
